# BattleShipDX asset editor

Single-file web app (`index.html`). Open your own `BattleShip.o2r` to browse textures, view levels in 3D, replace textures with PNG and build hi-res / music packs. Everything runs in the browser; no file is uploaded.

Published with GitHub Pages by `.github/workflows/pages.yml` (Settings → Pages → Source: GitHub Actions). To work on it locally, open `index.html` in a browser.
